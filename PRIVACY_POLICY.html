VitaBuddy 개인정보 보호정책

최종 업데이트: 2026년 1월 2일

1. 소개

VitaBuddy("우리", "저희" 또는 "앱")는 귀하의 개인정보 보호를 중요하게 생각합니다. 본 개인정보 보호정책은 VitaBuddy 모바일 애플리케이션("서비스")의 사용과 관련하여 귀하의 개인정보가 어떻게 수집, 사용, 공개되는지를 설명합니다.

2. 수집하는 정보

2.1 귀하가 제공하는 정보

  • 프로필 정보: 이름, 나이, 성별, 신장, 체중 (선택사항)
  • 식사 기록: 음식 이름, 칼로리, 섭취량
  • 운동 기록: 운동 종류, 시간, 강도, 칼로리 소모량
  • 체중 기록: 체중 측정 데이터와 날짜

2.2 자동으로 수집하는 정보

  • 건강 데이터: Health Connect/Google Health를 통해 제공되는 걸음 수, 칼로리 소모량, 운동 데이터
  • 앱 사용 데이터: 앱 사용 패턴, 기능 사용 빈도
  • 기기 정보: 기기 유형, 운영체제 버전, 언어 설정

3. 정보 사용 목적

수집된 정보는 다음과 같은 목적으로 사용됩니다:

  • 칼로리 관리: 정확한 칼로리 계산 및 건강 목표 달성 지원
  • 맞춤형 서비스: 사용자 프로필에 기반한 개인화된 식사 및 운동 추천
  • 건강 추적: 건강 데이터 분석 및 추세 파악
  • 앱 개선: 사용자 경험 향상 및 버그 수정

4. 정보 공유 및 공개

저희는 귀하의 개인정보를 다음과 같은 경우에만 공유합니다:

  • 법적 요구: 법적 의무 또는 법원 명령에 따라
  • 동의: 귀하의 명시적 동의가 있는 경우
  • 서비스 제공: 앱 기능 제공을 위해 필요한 제3자 서비스 (Health Connect 등)

중요: 저희는 어떠한 경우에도 귀하의 건강 데이터를 광고 목적으로 판매하거나 공유하지 않습니다.

5. 데이터 보안

저희는 귀하의 개인정보를 보호하기 위해 다음과 같은 조치를 취합니다:

  • 암호화: 모든 데이터는 안전하게 암호화되어 저장됩니다
  • 액세스 제한: 권한이 있는 직원만 데이터에 액세스할 수 있습니다
  • 정기 감사: 보안 시스템의 정기적 검토 및 업데이트

6. 데이터 보존

  • 활성 사용 기간: 계정이 활성화되어 있는 동안 데이터를 보존합니다
  • 삭제 요청: 사용자가 데이터 삭제를 요청하면 즉시 삭제합니다
  • 법적 의무: 법적 의무가 있는 경우 일정 기간 보존할 수 있습니다

7. 사용자 권리

귀하는 다음과 같은 권리를 가지고 있습니다:

  • 액세스: 자신의 데이터에 대한 액세스 요청
  • 수정: 부정확한 데이터의 수정 요청
  • 삭제: 데이터 삭제 요청
  • 이동: 데이터 이전 요청
  • 동의 철회: 건강 데이터 공유 동의 철회

8. 건강 데이터 처리

VitaBuddy는 Health Connect/Google Health를 통해 건강 데이터를 수집합니다:

  • 데이터 제어: 건강 데이터는 Health Connect/Google Health에서 직접 관리됩니다
  • 데이터 사용: 앱 내 칼로리 계산 및 건강 추적에만 사용됩니다
  • 데이터 저장: 모든 건강 데이터는 기기 내에서만 저장됩니다

9. 제3자 서비스

앱은 다음과 같은 제3자 서비스를 사용합니다:

9.1 건강 및 피트니스 데이터

  • Google Health Connect: 건강 데이터 수집

9.2 앱 프레임워크

  • Flutter: 앱 프레임워크

9.3 음식 검색 데이터 출처

인터넷 음식 검색 기능에서 다음 공개 데이터베이스를 활용합니다:

  • Open Food Facts: 글로벌 음식 데이터베이스 (ODbL 라이선스)
    • 사용 목적: 음식명, 칼로리, 영양 정보 검색
    • 데이터 저장: 검색 결과 캐시 (개인 사용 범위 내)
  • USDA FoodData Central: 미국 농무부 영양 데이터베이스 (공공 도메인)
    • 사용 목적: 음식명, 칼로리, 영양 정보 검색
    • 데이터 저장: 검색 결과 캐시 (개인 사용 범위 내)
  • Google ML Kit: 바코드 인식 (Apache 2.0 라이선스)
    • 사용 목적: 바코드/QR코드 스캔으로 음식 검색
    • 데이터 저장: 기기 내 임시 처리 (서버 전송 없음)

데이터 보호 약속: 모든 외부 데이터는 앱 내에서만 사용되며, 다른 목적으로 공유되지 않습니다.

10. 카메라 권한 사용

VitaBuddy는 다음과 같은 목적으로 카메라 권한을 사용합니다:

  • 바코드 스캔: 음식 포장지의 바코드를 스캔하여 자동으로 음식 정보를 검색
  • QR코드 인식: QR코드를 통한 빠른 음식 정보 입력

중요: 촬영된 이미지는 기기 내에서만 처리되며, 어떠한 서버로도 전송되지 않습니다. 바코드/QR코드 인식 후 즉시 폐기됩니다.

11. 아동 개인정보 보호

VitaBuddy는 13세 미만 아동을 대상으로 하지 않으며, 의도적으로 아동의 개인정보를 수집하지 않습니다.
